# I. Navigation and Exploration of Directories

### 1. Print Working Directory (`pwd`)
Use `pwd` whenever you need to check your current location in the filesystem hierarchy.

```bash
# Print current directory path
pwd
```

*Example Output:*
```text
/home/user/workshop/Day1
```

---

### 2. List Directory Contents (`ls`)
Lists the files and folders located in the specified directory (or the current directory if none is specified).

**Syntax:**
```bash
ls [options] [directory_to_list]
```

**Common Options:**
- `-l`: Long listing format (displays permissions, owner, group, file size, and timestamp).
- `-h`: Human-readable file sizes (e.g., `4K`, `25M`, `2G` instead of raw byte counts; used with `-l`).
- `-a`: Show all files, including hidden files (entries starting with `.`).
- `-r`: Reverse order while sorting.
- `-R`: Recursively list all subdirectories.
- `-s`: Print the allocated size of each file in blocks.
- `-S`: Sort files by size, largest first.
- `-t`: Sort by modification time, newest first (useful to verify recently generated files).

**Examples:**
```bash
# Basic listing
ls

# Long listing with human-readable sizes
ls -lh

# Sort by modification time (newest first)
ls -lht

# Show hidden files and directories
ls -la

# List files matching a pattern using wildcards (*)
ls *.txt
ls *.fastq.gz
```

---

### 3. Create Directories (`mkdir`)
Creates one or more new directories.

**Syntax:**
```bash
mkdir [options] <directory_name>
```

**Common Options:**
- `-p`: Create parent directories as needed without throwing an error if they already exist.
- `-v`: Verbose mode (prints a confirmation message for each created directory).
- `-m`: Set file permission mode (similar to `chmod`).

**Examples:**
```bash
# Create a single directory
mkdir my_directory

# Create nested directory structures in one step
mkdir -p project/data/raw_reads

# Create nested directories with verbose output
mkdir -pv analysis/results/qc

# Create a directory with explicit read/write permissions
mkdir -m 755 shared_folder
```

---

### 4. Change Directory (`cd`)
Changes the current working directory to the specified destination.

**Syntax:**
```bash
cd <target_directory>
```

**Special Directory Shortcuts:**
- `~` (Tilde): User's home directory (e.g., `/home/username`).
- `.` (Single Dot): Current directory.
- `..` (Double Dot): Parent directory (one level up).
- `-` (Hyphen): Switch back to the previous directory.

**Examples:**
```bash
# Verify current location
pwd
# Output: /home/user

# Move into the Documents directory
cd Documents
pwd
# Output: /home/user/Documents

# Move one level up to the parent directory
cd ..

# Jump directly to your home directory
cd ~
# Or simply:
cd

# Move using an absolute path
cd /home/user/project/data
```

---

### 5. Create and Edit Files with `nano`
`nano` is a simple, beginner-friendly command-line text editor.

**Usage:**
```bash
nano My_file.txt
```

**Step-by-Step Instructions:**
1. Type `nano My_file.txt` and press `Enter`.
2. Type your text (e.g., `Testing nano text editor`).
3. Press `Ctrl + O` to save (WriteOut) the file, then press `Enter` to confirm the filename.
4. Press `Ctrl + X` to exit the editor.

# II. File Inspection and Viewing Content

### 1. Display Entire File Content (`cat`, `less`, `more`)

* **`cat` (Concatenate):** Prints the entire file directly to the terminal. Best suited for short files.
* **`less`:** An interactive pager that allows scrolling up and down through large files without loading the whole file into memory. (Press `q` to quit, `/pattern` to search).
* **`more`:** A legacy pager that scrolls downward screen by screen.

```bash
# Print full content
cat filename.txt

# Inspect interactively (press 'q' to exit)
less large_file.txt

# Paginated view
more filename.txt
```

---

### 2. View Top Lines of a File (`head`)
Prints the first few lines of a file (default is 10 lines).

**Syntax:**
```bash
head [options] <file_name>
```

**Common Options:**
- `-n <num>`: Show the first `<num>` lines.
- `-c <num>`: Show the first `<num>` bytes.
- `-q`: Suppress file header banners when viewing multiple files.

**Examples:**
```bash
# View first 10 lines (default)
head filename.txt

# View first 20 lines
head -n 20 filename.txt

# View first 50 lines across multiple files
head -n 50 sample1.fastq sample2.fastq
```

---

### 3. View Bottom Lines of a File (`tail`)
Prints the last few lines of a file (default is 10 lines).

**Syntax:**
```bash
tail [options] <file_name>
```

**Common Options:**
- `-n <num>`: Show the last `<num>` lines.
- `-n +<num>`: Start printing from line number `<num>` to the end of the file.
- `-f`: Follow file growth in real time (useful for monitoring log files).

**Examples:**
```bash
# View last 10 lines (default)
tail filename.txt

# View last 15 lines
tail -n 15 filename.txt

# View file starting from line 100 onwards
tail -n +100 filename.txt

# Monitor pipeline progress in real time
tail -f pipeline.log
```

# III. Copying, Moving, and Removing Files

### 1. Copy Files and Directories (`cp`)
Copies source files or directories to a specified destination.

**Syntax:**
```bash
cp [options] <source> <destination>
```

**Common Options:**
- `-i`: Interactive prompt before overwriting existing destination files.
- `-f`: Force overwrite of destination files.
- `-u`: Update; copy only when source is newer than destination or destination is missing.
- `-r` or `-R`: Copy directories recursively.
- `-p`: Preserve file attributes (timestamps, ownership, permissions).

**Examples:**
```bash
# Copy a single file into an existing directory
cp sample.txt backup/

# Copy with overwrite confirmation prompt
cp -i sample.txt backup/

# Copy an entire directory recursively
cp -r raw_data/ raw_data_backup/
```

---

### 2. Move or Rename Files (`mv`)
Used to move files/directories to another directory or rename them in place.

> [!NOTE]
> Unlike `cp`, `mv` does not require a `-r` flag to move directories—it moves entire directory structures automatically.

**Syntax:**
```bash
mv [options] <source> <destination>
```

**Common Options:**
- `-i`: Prompt before overwriting an existing file.
- `-f`: Force overwrite without prompting.
- `-u`: Move only if source is newer than destination.
- `-n`: Do not overwrite an existing file.

**Examples:**
```bash
# Rename a file in the current directory
mv old_name.txt new_name.txt

# Move a file to another folder
mv sample.txt results/

# Move and rename at the same time with interactive confirmation
mv -i sample.txt results/sample_renamed.txt
```

---

### 3. Remove Files and Directories (`rm`)
Permanently deletes files or directories.

> [!CAUTION]
> Files deleted with `rm` do NOT go to a trash or recycle bin. Deletions are permanent and irreversible!

**Syntax:**
```bash
rm [options] <target>
```

**Common Options:**
- `-i`: Prompt before every removal.
- `-f`: Force removal; ignores nonexistent files and never prompts.
- `-r` or `-R`: Remove directories and their contents recursively.
- `-d`: Remove empty directories (similar to `rmdir`).
- `-v`: Verbose output explaining each action taken.

**Examples:**
```bash
# Remove a single file
rm unwanted_file.txt

# Interactively remove files
rm -i sample.txt

# Recursively remove an entire directory with confirmation
rm -r my_directory/

# Forcefully remove a temporary directory and its contents
rm -rf temp_directory/
```

# IV. Standard Streams and I/O Redirection

Unix commands communicate via three standard data streams:
1. **Standard Input (`stdin`, File Descriptor 0):** Input stream fed into a program (keyboard or piped data).
2. **Standard Output (`stdout`, File Descriptor 1):** Normal output stream printed by a program.
3. **Standard Error (`stderr`, File Descriptor 2):** Error diagnostic stream generated by a program.

### Redirection Operators
* `>`: Redirect `stdout` to a file, **overwriting** existing content.
* `>>`: Redirect `stdout` to a file, **appending** to the end of existing content.
* `<`: Redirect `stdin` from a file into a command.
* `2>`: Redirect `stderr` to a file.
* `&>` or `2>&1`: Redirect both `stdout` and `stderr` together.

**Examples:**
```bash
# Overwrite stdout into a new file
echo "First line of text" > a_short_file.txt

# Append another line to the existing file
echo "Second line of text" >> a_short_file.txt

# Redirect stdout and stderr separately
my_program > stdout_log.txt 2> error_log.txt

# Redirect both stdout and stderr to the same file
my_program > full_run.log 2>&1
```

# V. Filesystem Concepts: Absolute vs. Relative Paths

* **Absolute Path:** The full path starting from the root directory (`/`) or home (`~`). It points to the exact same file regardless of where you currently are.
  * *Example:* `/home/user/project/data/sample.fq`
* **Relative Path:** A path defined relative to your current working directory (`.`).
  * *Example:* If you are in `/home/user/project`, the relative path is `data/sample.fq`.
  * *Example:* Moving one directory back and then into another folder: `../reference/genome.fa`.

```bash
# Absolute path example
cat /home/user/data/sample.txt

# Relative path examples
cat ./sample.txt
cat ../reference/genes.gtf
```

# VI. Compression and Archiving

Bioinformatics data (e.g., FASTQ, VCF, BAM) is large and routinely compressed.

### 1. `gzip` and `gunzip`
Standard compression format for individual sequencing files (`.gz`).

```bash
# Compress file (replaces sample.fq with sample.fq.gz)
gzip sample.fq

# Compress while keeping original uncompressed file (-k)
gzip -k sample.fq

# Decompress .gz file
gunzip sample.fq.gz
# Or:
gzip -d sample.fq.gz
```

### 2. `tar` (Tape Archive)
Bundles multiple files/directories into a single archive file, frequently paired with gzip (`.tar.gz` or `.tgz`).

**Common Flags:**
- `-c`: Create a new archive.
- `-x`: Extract files from an archive.
- `-z`: Compress or decompress using gzip.
- `-v`: Verbose output showing files being processed.
- `-f`: Specify the archive filename.

```bash
# Create a compressed tarball archive
tar -czvf project_backup.tar.gz project_folder/

# Extract a compressed tarball archive
tar -xzvf project_backup.tar.gz
```

### 3. `bzip2` and `zip`
```bash
# Compress with bzip2 (higher compression ratio, slower)
bzip2 -k sample.txt

# Decompress bzip2 file
bunzip2 sample.txt.bz2

# Create standard .zip archive of a folder (e.g. packaging Day2 practice data)
zip -r Day2.zip Day2/

# Unzip .zip archive
unzip Day2.zip

# Move into the unzipped directory to work directly with its files
cd Day2
```
