# Background: Common Genomics File Formats

### 1. FASTQ Format (Raw Sequencing Reads)
Every single sequencing read in a FASTQ file is represented by **4 consecutive lines**:
1. **Line 1 (Header):** Starts with an `@` character followed by the read identifier and run metadata.
2. **Line 2 (Sequence):** The raw nucleotide sequence (`A`, `C`, `G`, `T`, `N`).
3. **Line 3 (Separator):** Starts with a `+` symbol (optionally followed by the read ID).
4. **Line 4 (Quality Scores):** ASCII-encoded Phred quality scores corresponding base-for-base with Line 2.

### 2. FASTA Format (Reference Genomes and Gene Sequences)
A FASTA file contains nucleotide or peptide sequences:
- **Header line:** Starts with `>` followed by sequence ID and description.
- **Sequence lines:** One or more lines containing the sequence string.

# I. File Integrity and File Type Verification

Before running bioinformatics pipelines on downloaded raw data, always verify file completeness and format.

### 1. Check File Integrity (`md5sum`)
MD5 checksums generate a 32-character hexadecimal fingerprint. If even a single character in the file changes, the MD5 checksum changes completely.

```bash
# Create two sample test files
echo "My name is Sandeep" > sandeep.txt
echo "My name is Sandeep." > sandeep1.txt

# Calculate MD5 checksums
# Linux (GNU coreutils):
md5sum sandeep.txt
md5sum sandeep1.txt

# macOS alternative:
md5 sandeep.txt sandeep1.txt
```

*Expected Observation:* Even though the files differ by only a single period (`.`), their MD5 hashes are entirely distinct.

### 2. Determine File Type (`file`)
Do not rely solely on file extensions. The `file` command inspects the file header magic bytes to report the real MIME type and compression.

```bash
# Check plain text file
file sandeep.txt
# Output: sandeep.txt: ASCII text

# Check compressed sequencing read archive
file Test.fq.gz
# Output: Test.fq.gz: gzip compressed data
```

# II. Sequence and Read Counting in Sequencing Data

> [!TIP]
> Viewing compressed files:
> - On Linux: `zcat file.fq.gz` or `zless file.fq.gz`
> - On macOS: `gzcat file.fq.gz` or `zcat < file.fq.gz`

### 1. Count Total Lines and Reads
Since each FASTQ record is exactly 4 lines, dividing the total line count by 4 gives the exact number of sequenced reads:

```bash
# Total line count in compressed FASTQ
zcat Test.fq.gz | wc -l

# Calculate total read count (lines divided by 4)
echo "$(( $(zcat Test.fq.gz | wc -l) / 4 )) reads"
```

### 2. Count Reads by Header Prefix
You can also count reads by matching the unique identifier prefix on line 1 (e.g., SRA/ENA runs usually begin with `@ERR` or `@SRR`):

```bash
# Count lines starting with '@ERR'
zcat Test.fq.gz | grep -c "^@ERR"
```

### 1. Extract Fields and Columns (`cut`)
Extracts vertical sections or fields from delimited tabular data (e.g., BED, GFF, VCF, SAM).

**Syntax:**
```bash
cut [options] [file]
```

**Common Options:**
- `-d <delimiter>`: Field delimiter (default is Tab).
- `-f <list>`: Select specific field numbers (e.g., `-f 1`, `-f 1,3`, or `-f 1-4`).
- `-c <range>`: Cut by character position (e.g., `-c 1-5`).
- `-b <range>`: Cut by byte position.

**Examples with `id.txt`:**
```bash
# View sample file
cat id.txt

# Extract characters by range
cut -c 1-3 id.txt      # First 3 characters
cut -c 3-6 id.txt      # Characters from position 3 to 6
cut -c 3- id.txt       # From character 3 to end of line

# Extract delimited fields (e.g., splitting by underscore)
cut -d "_" -f 1 id.txt       # Field 1 only
cut -d "_" -f 2 id.txt       # Field 2 only
cut -d "_" -f 1,2 id.txt     # Fields 1 and 2
```

---

### 2. Merge Files Horizontally (`paste`)
Merges lines of files side-by-side (tab-delimited by default), or reshapes multi-line records.

**Syntax:**
```bash
paste [options] file1 file2
```

**Common Options:**
- `-d <delimiter>`: Use a custom delimiter instead of Tab.
- `-s`: Paste lines of each file serially (horizontally into one line per file).

**Examples:**
```bash
# View both files
cat id.txt
cat family.txt

# Merge side-by-side with default tab separator
paste id.txt family.txt

# Merge with custom pipe '|' delimiter
paste -d "|" id.txt family.txt

# Merge all lines of a file into a single line
paste -s id.txt
```

> [!IMPORTANT]
> **The `paste - - - -` FASTQ Idiom:**
> The special construct `paste - - - -` takes 4 consecutive lines from standard input and joins them into a single tab-separated row. This turns a 4-line FASTQ read into a single tabular row:
> - Field 1 = Header
> - Field 2 = Sequence
> - Field 3 = `+`
> - Field 4 = Quality Score
>
> ```bash
> # Turn 4-line reads into 1-line records, then extract only the nucleotide sequence (Field 2)
> zcat Test.fq.gz | paste - - - - | cut -f 2 | head -n 5
> ```

### 3. Word, Line, and Character Counting (`wc`)
Computes line counts, word counts, and byte/character lengths.

**Syntax:**
```bash
wc [options] [file]
```

**Common Options:**
- `-l`: Count lines only.
- `-w`: Count words only.
- `-c`: Count bytes/characters only.
- `-L`: Print the length of the longest line.

**Examples:**
```bash
# Full count (lines, words, characters)
wc id.txt

# Count lines only
wc -l id.txt

# Find the length of the longest sequence in a file
wc -L id.txt
```

---

### 4. Pattern Matching and Filtering (`grep`)
Searches files or streams for regular expression patterns.

**Syntax:**
```bash
grep [options] "pattern" [file]
```

**Common Options:**
- `-c`: Print count of matching lines only.
- `-n`: Print line number alongside matches.
- `-i`: Case-insensitive search.
- `-w`: Match whole words only.
- `-v`: Invert match (print lines that do **not** match).
- `-A <num>`: Print `<num>` lines of trailing context **After** match.
- `-B <num>`: Print `<num>` lines of leading context **Before** match.

**Genomics Examples with `Test.fa`:**
```bash
# Count total sequences in a FASTA file (matching header prefix '>')
grep -c "^>" Test.fa

# Count non-header sequence lines (invert match)
grep -v "^>" Test.fa | wc -l

# Search for pattern "Seq" (case-insensitive)
grep -ci "Seq" Test.fa

# Show line numbers of matching lines
grep -in "Seq" Test.fa

# Print matching header PLUS the 1 sequence line immediately after it (-A 1)
grep -A 1 "Seq" Test.fa

# Print matching sequence PLUS the 1 header line immediately before it (-B 1)
grep -B 1 "Seq" Test.fa
```

---

### 5. Sorting Lines (`sort`)
Sorts text files line-by-line numerically or alphabetically.

**Syntax:**
```bash
sort [options] [file]
```

**Common Options:**
- `-n`: Numerical sort (sorts `2` before `10`, unlike standard alphabetical sort).
- `-r`: Reverse sort order.
- `-k <field>`: Sort by specific column key (1-indexed).
- `-b`: Ignore leading blanks/whitespace.
- `-u`: Sort and keep only unique lines (equivalent to `sort | uniq`).

**Examples with `Features.txt` and `Exon.txt`:**
```bash
# Default alphabetical sort
sort Features.txt

# Sort numerically by Column 1
sort -n Exon.txt

# Sort numerically by Column 2
sort -n -k 2 Exon.txt

# Sort numerically by Column 2 in reverse order (highest first)
sort -n -k 2 -r Exon.txt
```

---

### 6. Deduplicating and Frequency Counting (`uniq`)
Filters out or reports repeated lines.

> [!NOTE]
> `uniq` only detects adjacent duplicate lines. **You must run `sort` before `uniq`** on unsorted input.

**Syntax:**
```bash
uniq [options] [file]
```

**Common Options:**
- `-c`: Prefix lines with their occurrence count.
- `-d`: Print only repeated (duplicate) lines.
- `-u`: Print only unique lines (lines that appear exactly once).
- `-i`: Ignore case differences.

**Examples with `Exon.txt`:**
```bash
# Remove adjacent duplicate lines
sort Exon.txt | uniq

# Count frequencies of each item in Column 1
cut -d " " -f 1 Exon.txt | sort | uniq -c

# Show only items that appear more than once
cut -d " " -f 1 Exon.txt | sort | uniq -d

# Show only items that appear exactly once
cut -d " " -f 1 Exon.txt | sort | uniq -u
```

---

### 7. Wrapping Lines (`fold`)
Breaks lines at specified character widths.

```bash
# Break sequence or column text into 1 character per line
fold -w 1 Exon.txt | head -n 10

# Count character frequencies across an entire file
fold -w 1 Exon.txt | sort | uniq -c
```

---

### 8. Stream Editing and Replacement (`sed`)
Performs text substitution and pattern transformations.

**Syntax:**
```bash
sed 's/<pattern_to_match>/<replacement_string>/[flags]' [file]
```

**Common Flags:**
- `g`: Global replacement (replace all occurrences per line, not just the first).
- `i`: Case-insensitive match (GNU sed).
- `-n` with `/p`: Print only lines where substitution succeeded or pattern matched.

**Examples:**
```bash
# Substitute 'exon' with 'mRNA' across the file
sed 's/exon/mRNA/g' Exon.txt

# Print only lines between pattern 'Start' and 'End'
sed -n '/PatternStart/,/PatternEnd/p' Filename.txt
```

# IV. Genomics Math: Nucleotide Composition & Melting Temperature ($T_m$)

We can combine all the tools above into a single pipeline to extract raw nucleotide counts and calculate genomic statistics.

### 1. Calculate Base Counts (A, C, G, T) from FASTQ
```bash
# Extract read sequences -> collapse newlines -> fold into single bases -> count frequencies
zcat Test.fq.gz | paste - - - - | cut -f 2 | tr -d '\n' | fold -w 1 | sort | uniq -c
```

*Example Output with `Test.fq.gz`:*
```text
 174 A
 225 C
 191 G
 264 T
```

---

### 2. Automate Base Count Storage and Arithmetic in Bash
We can extract individual counts cleanly using `grep`, `sed`, and `cut`, and calculate totals using the `bc` precision calculator:

```bash
# Store base counts into variables
# Extract nucleotide counts using grep, sed, and cut (tools taught in this tutorial)
A=$(zcat Test.fq.gz | paste - - - - | cut -f 2 | tr -d '\n' | fold -w 1 | sort | uniq -c | grep -w "A" | sed 's/^ *//' | cut -d " " -f 1)
T=$(zcat Test.fq.gz | paste - - - - | cut -f 2 | tr -d '\n' | fold -w 1 | sort | uniq -c | grep -w "T" | sed 's/^ *//' | cut -d " " -f 1)
G=$(zcat Test.fq.gz | paste - - - - | cut -f 2 | tr -d '\n' | fold -w 1 | sort | uniq -c | grep -w "G" | sed 's/^ *//' | cut -d " " -f 1)
C=$(zcat Test.fq.gz | paste - - - - | cut -f 2 | tr -d '\n' | fold -w 1 | sort | uniq -c | grep -w "C" | sed 's/^ *//' | cut -d " " -f 1)

# Verify counts
echo "A: $A | T: $T | G: $G | C: $C"

# Calculate Total Nucleotides
TOTAL=$(echo "$A + $T + $G + $C" | bc)
echo "Total Valid Bases: $TOTAL"

# Calculate GC Content percentage: (G + C) / Total * 100
GC_PERCENT=$(echo "scale=2; (($G + $C) * 100) / $TOTAL" | bc)
echo "GC Content: $GC_PERCENT %"

# Calculate approximate Primer Melting Temperature (Tm) using Wallace Rule:
# Tm = 2*(A+T) + 4*(G+C)
TM=$(echo "(2 * ($A + $T)) + (4 * ($G + $C))" | bc)
echo "Wallace Rule Metric: $TM"
```

# V. Hands-on Practice: Assignment 1

Test your understanding of Unix text processing using **only** the tools taught in this tutorial (`paste`, `cut`, `sed`, `tr`, `fold`, `grep`, `sort`, `uniq`, `head`, `tail`):

### 1. Convert FASTQ to FASTA
**Goal:** Extract header (Line 1) and sequence (Line 2) from FASTQ format, change `@` to `>`, and reformat into FASTA.
```bash
# Solution using paste, cut, sed, and tr:
zcat Test.fq.gz | paste - - - - | cut -f 1,2 | sed 's/^@/>/' | tr '\t' '\n' > output.fa

# Alternative using sed directly (selecting lines 1 and 2 of every 4-line record):
zcat Test.fq.gz | sed -n '1~4s/^@/>/p; 2~4p' > output.fa
```

### 2. Split a Multi-FASTA File into Separate Files per Sequence
**Goal:** Split a multi-sequence FASTA file into individual sequence files.
```bash
# Solution using csplit (split at each line matching '>'):
csplit -z -f seq_ -b "%02d.fa" Test.fa '/>/' '{*}'

# Alternative using grep, a while read loop, and sed:
grep "^>" Test.fa | tr -d ">" | while read id; do
    sed -n "/>$id/,/>/p" Test.fa | sed '$d' > "${id}.fa"
done
```

### 3. Conversion Between Single-Line and Multi-Line FASTA Sequences
**Goal:** Convert multi-line sequences into single-line sequences, or wrap single-line sequences into multiple lines.

* **Multi-Line to Single-Line FASTA:**
```bash
# Using tr and sed to join sequence lines while preserving header lines:
cat input.fa | tr '\n' '\t' | sed 's/\t>/\n>/g' | sed 's/\t/\n/' | tr -d '\t' > single_line.fa
```

* **Single-Line to Multi-Line FASTA (wrapping at 60 characters):**
```bash
# Using fold -w 60 (taught in Section III.7):
fold -w 60 sequence_only.txt

# Or using sed to insert a newline after every 60 characters:
sed 's/.\{60\}/&\n/g' sequence_only.txt
```

### 4. Random Dataset Generation / Subsampling for FASTQ and FASTA
**Goal:** Extract a subset of reads/sequences for quick testing.
```bash
# Extract the first 1,000 reads (4,000 lines) from FASTQ using head:
zcat Test.fq.gz | head -n 4000 | gzip > subset_1k.fq.gz

# Extract the first 100 sequences from a single-line FASTA using head:
head -n 200 Test.fa > subset_100.fa
```

### 5. Extract a Specific Gene / Sequence of Interest from Genome File
**Goal:** Extract the sequence for a specific entry (e.g., `>Gene_123`) from a FASTA file.
```bash
# Using sed pattern range (as taught in Section III.8):
sed -n '/>Gene_123/,/>/p' genome.fa | sed '$d'

# If the FASTA has single-line sequences, use grep with context line -A 1 (taught in Section III.4):
grep -A 1 "^>Gene_123" genome.fa
```

### 6. Creation of Non-Redundant Dataset (Deduplication)
**Goal:** Remove duplicate identical sequences from a FASTA dataset.
```bash
# Solution using paste, sort, and tr:
# 1. Turn pairs of lines (Header and Sequence) into single tab-separated lines:
# 2. Sort uniquely by the sequence column (Column 2) using sort -k 2,2 -u:
# 3. Restore newlines using tr:
cat input.fa | paste - - | sort -k 2,2 -u | tr '\t' '\n' > non_redundant.fa
```
